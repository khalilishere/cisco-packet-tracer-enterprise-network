# Netzwerkdokumentation

Dieses Verzeichnis enthält die technische Dokumentation
des Cisco-Packet-Tracer-Projekts.

- Router_Config.txt: Router-Konfiguration und Befehlsausgaben
- Switch_Config.txt: Switch-Konfiguration und VLAN-Informationen
- Netzwerkdokumentation.txt: Netzwerkübersicht, IP-Adressierung und Funktionstests
