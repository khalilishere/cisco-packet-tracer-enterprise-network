
========================================
ROUTER CONFIGURATION
Projekt: Unternehmensnetzwerk
Software: Cisco Packet Tracer
========================================

1. NETZWERKÜBERSICHT
--------------------
Konzept:          Router-on-a-Stick
Routing:          Inter-VLAN-Routing
IP-Adressierung:  IPv4
Router-Interface: GigabitEthernet0/0/0

VLAN | Name       | Subnetz          | Gateway
-----|------------|------------------|----------------
10   | IT         | 192.168.10.0/24  | 192.168.10.1
20   | VERWALTUNG | 192.168.20.0/24  | 192.168.20.1

SERVER
------
FTP-Server:
IP-Adresse: 192.168.10.10
Subnetzmaske: 255.255.255.0
Gateway: 192.168.10.1
VLAN: 10 (IT)
IP-Konfiguration: Statisch

DNS-Server für DHCP-Clients:
8.8.8.8

DHCP
----
Für beide Subnetze sind die Adressen .1 bis .99
von der DHCP-Vergabe ausgeschlossen.
Dynamische Client-Adressen werden ab .100 vergeben.

2. WICHTIGE SHOW-BEFEHLE
------------------------
enable
show running-config
show ip interface brief
show ip route
show ip dhcp binding

3. ROUTER-SUBINTERFACES
-----------------------
interface GigabitEthernet0/0/0
 no ip address
 no shutdown
exit

interface GigabitEthernet0/0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
exit

interface GigabitEthernet0/0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
exit

HINWEIS:
Das physische Router-Interface ist mit dem
Switch verbunden. Die VLANs werden über
802.1Q-Subinterfaces geroutet.

4. DHCP-KONFIGURATION
---------------------
ip dhcp excluded-address 192.168.10.1 192.168.10.99
ip dhcp excluded-address 192.168.20.1 192.168.20.99

ip dhcp pool IT_Pool
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8
exit

ip dhcp pool Verwaltung_Pool
 network 192.168.20.0 255.255.255.0
 default-router 192.168.20.1
 dns-server 8.8.8.8
exit

5. FUNKTIONSTESTS
-----------------
Inter-VLAN-Routing:
Kommunikation zwischen Clients in VLAN 10
und VLAN 20 per Ping erfolgreich getestet.

DHCP:
Clients in beiden VLANs erhalten ihre
IP-Konfiguration automatisch.
Kontrolle mit: show ip dhcp binding

Server-Erreichbarkeit:
Der FTP-Server unter 192.168.10.10 ist
aus VLAN 20 per Ping erreichbar.

FTP:
FTP-Verbindung zum Server über
ftp 192.168.10.10 erfolgreich getestet.
Anmeldung und Dateizugriff wurden getestet.

6. KONFIGURATION SPEICHERN
--------------------------
copy running-config startup-config
